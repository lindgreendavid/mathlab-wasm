# Contributing

Contributions are welcome through focused issues and pull requests.

1. State the numerical claim or defect precisely.
2. Cite a primary or authoritative source when changing mathematical behavior.
3. Add a deterministic regression test before changing a solver.
4. Keep observed results separate from theoretical guarantees.
5. Run formatting, linting, Rust tests, report validation, and browser tests.

Do not silently change the frozen v0.1 protocol or overwrite its report. Amendments require a new
versioned protocol and report with the timing and reason recorded.
