# v0.2.0 release audit

**Audit date:** 2026-08-14

## Scope

This audit gates the safeguarded root-finding extension. Product version 0.2.0 adds a
Brent–Dekker-style pedagogical implementation without changing the frozen v0.1 study or claiming
equivalence with a production numerical library.

## Prespecification identity

- Protocol: [`docs/protocol-v0.2.md`](protocol-v0.2.md)
- Protocol commit: `e4c6f222c22f163b909503d05ead800394757f26`
- The protocol commit was pushed before safeguarded-solver implementation and result generation.
- Machine-readable result:
  [`reports/v0.2-safeguarded-root-finding.json`](../reports/v0.2-safeguarded-root-finding.json)

## Confirmatory result

- All five frozen status expectations pass.
- All three iterative estimates are within `1e-9` of their fixed references.
- Every recorded nonterminal bracket contains its fixed reference and has non-increasing width
  within the frozen comparison allowance.
- The skewed `x¹⁰−1` case contains accepted secant, inverse-quadratic, and bisection steps.
- The exact endpoint root uses two initial evaluations and zero iterative updates.
- The even-multiplicity example is rejected as an invalid sign-changing bracket, not declared
  root-free.
- The first Ubuntu run exposed a last-bit system-libm difference in a cosine residual. The dated
  post-result protocol amendment withdraws cross-platform byte identity and replaces it with exact
  structural comparison plus a `16 × ε`-scaled floating-point allowance. No status, count, step
  kind, bracket decision, or frozen tolerance outcome differed.

## Release gate

The final commit must pass Rust formatting, Clippy with warnings denied, twelve native tests,
byte-for-byte regeneration of v0.1, semantic cross-platform comparison of v0.2, WebAssembly build, static content checks,
JavaScript syntax, browser interaction, WCAG A/AA automation, 390 px responsive testing, CodeQL,
RustSec, and package audit.

## Remaining limits

- Five selected v0.2 cases do not estimate prevalence or establish a universal solver ranking.
- No timing endpoint, discontinuous/noisy-function study, interval arithmetic, or external-library
  equivalence test is included.
- “Safeguarded” is conditional on a valid continuous sign-changing bracket and the documented
  floating-point implementation.
