# v0.1.0 release audit

**Audit date:** 2026-08-14

## Scope

This audit gates the first public release of Mathlab WASM as an educational research product. It
does not claim novel numerical analysis or production-solver maturity.

## Completed checks

- The research question, seven scenarios, endpoints, tolerances, and expected qualitative outcomes
  were frozen before the committed benchmark generator was executed.
- NIST DLMF §3.8, Brent (1971), IEEE 754-2019 metadata, Rust `f64`, and `wasm-bindgen`
  documentation were checked and mapped to bounded claims.
- The Rust library, native tests, report generator, and browser use one solver implementation.
- Eight numerical regression tests pass.
- All seven frozen report expectations pass.
- Rust formatting and Clippy with warnings denied pass.
- The WebAssembly package builds from the locked dependency graph.
- Static research/accessibility contracts and JavaScript syntax checks pass.
- Three browser tests pass: WASM interaction, automated WCAG A/AA rules, and 390 px overflow.
- npm audit reports zero known vulnerabilities after upgrading Playwright to 1.62.1.

## Remaining limits

- Small, intentionally selected benchmark suite; no representativeness claim.
- No Brent implementation, interval arithmetic, noisy-function study, or workload timing.
- Automated accessibility testing does not replace a complete manual WCAG audit.
- The browser visualization is explanatory; the machine-readable Rust trace is authoritative.
