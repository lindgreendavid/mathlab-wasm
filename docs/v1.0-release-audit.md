# v1.0.0 release audit

**Audit date:** 2026-08-14

## Scope and identity

This audit gates the stable conditioning-diagnostic release. It adds no new solver ranking and does
not alter the frozen v0.1 or v0.2 registers.

- Protocol: [`docs/protocol-v1.0.md`](protocol-v1.0.md)
- Frozen protocol commit: `97b21a2`
- Result: [`reports/v1.0-conditioning.json`](../reports/v1.0-conditioning.json)
- Product version: `1.0.0`; earlier study versions remain part of their historical artifact names.

## Confirmatory result

- All five case classifications and all three global checks pass.
- The three scaled linear equations have identical computed forward error, residual ordering over
  sixteen orders of magnitude, and inverse condition-number ordering.
- All three linear first-order estimates equal their computed forward error within the frozen
  binary64 allowance.
- The cubic estimate agrees with forward error within the prespecified relative tolerance.
- The repeated-root result serializes condition and estimate as `null`, with no invented finite
  bound.
- Website values are loaded from the committed result, with the perturbation model and limits shown
  beside the interaction.

## Release gate

The release commit must pass formatting, Clippy with warnings denied, all native regression tests,
deterministic regeneration of the three reports, WebAssembly build, static research checks,
JavaScript syntax, browser interaction, automated WCAG A/AA checks, 390 px responsive testing,
CodeQL, RustSec, and dependency audit. The final audit records the exact commit and public links
after merge.

## Remaining limits

- Five selected cases demonstrate possibility, not prevalence.
- The condition number is specific to additive function-value perturbations and is not scale free.
- The cubic estimate is local and first-order, not a rigorous enclosure.
- Multiple roots, noisy functions, interval methods, and applied workloads require separate frozen
  studies.
